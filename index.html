🔌 Cara Menghubungkan Alat Digitalisasi

Perangkat yang difasilitasi dapat saling terhubung untuk melengkapi kebutuhan pendidikan. Ponsel pribadi juga dapat dihubungkan dengan perangkat tersebut.

A. Menghubungkan Hardisk/SSD

Dengan menghubungkan Hardisk/SSD, pengguna dapat membaca file di dalamnya dan memindahkan data dari komputer maupun perangkat lain, seperti menghubungkan flashdisk.

🔗 USB to Type-C🔗 Type-C to Type-C
Klik perangkat untuk melihat penjelasan koneksinya.

B. Menghubungkan PID ke Perangkat Lain

PID dapat menampilkan atau memproyeksikan layar perangkat lain agar terlihat oleh seluruh siswa. Berbeda dengan proyektor biasa, PID tetap menyediakan fungsi interaktif pada metode proyeksi yang mendukungnya.

Klik node untuk melihat penjelasan metode proyeksi.
